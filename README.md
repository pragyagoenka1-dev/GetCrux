# Ad Library — Explore prototype

An interactive prototype of an ad-library Explore experience: a masonry grid of ad creatives, saved Views, a brand-aware Filters panel, and an ad detail view with suggestions.

Prototype / design exploration. Data and images are representative mock content.

Live: https://pragyagoenka1-dev.github.io/GetCrux/

## How it is published

The whole prototype is one self-contained index.html, with its styles, script and images built in. GitHub Pages serves it straight from the main branch.

To update the site, upload a new index.html to the repo root and commit to main. It goes live in about a minute.

The .nojekyll file tells GitHub Pages to publish the files exactly as uploaded.
